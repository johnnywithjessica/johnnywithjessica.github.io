Johnny & Jessica — wedding website draft
2027/03/06 · CHALET V · Taipei

Open index.html in a browser to preview. This is a static website with relative
asset paths, ready to place in a GitHub Pages publishing directory. There is no
build step, package installation, or server required for the website itself.

RSVP is intentionally shown as coming soon. No responses are collected.
When your form is ready, enter its URL in config.js under rsvpUrl. The button
will then appear. You may also add a bilingual rsvpDeadline message there.

Before publishing, review the draft invitation wording, photo choices, map
destination and event details. Parking, transit, RSVP deadline, dress code and
contact details have not been supplied and are not invented in this draft.
The calendar file uses Taiwan time, with the ceremony at 17:30 and banquet
at 18:30 noted in the description. No event end time has been assumed.

Photos are optimized copies of 搶先看15.jpg, 搶先看12.jpg, 搶先看17.jpg,
and 搶先看39.jpg from your supplied folder. Originals are untouched.
The exported JPEGs contain no original EXIF metadata.

No external fonts, analytics, form backend or third-party embeds are used.
The Google Maps link opens in a separate tab.
This draft has not been uploaded to GitHub or published online.
